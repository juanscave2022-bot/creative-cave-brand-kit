# Fonts

| Font | Role | In this repo? | Where to get it |
|---|---|---|---|
| **SF Pro** | Official brand font: headlines, body, labels | No | Free download from Apple: https://developer.apple.com/fonts/ |
| **Inter** | Closest free match to SF Pro, used when SF Pro isn't available | Yes, `Inter/` | https://rsms.me/inter/ |
| **Yellowtail** | Script accent, one coral word at a time | No | Free on Google Fonts: https://fonts.google.com/specimen/Yellowtail |
| **Anton** | Live labels on the site (game score and similar) | No | Free on Google Fonts: https://fonts.google.com/specimen/Anton |
| **Canyon** | Ranch display lettering: badges, merch, section titles | No | Madeline O'Donoghue Studio (paid license) |

## Why some files are not here

- **SF Pro** is Apple's font. Their license does not allow passing the files around, so each person downloads it from Apple directly.
- **Canyon** is on a Standard Font Licence for one user. The license does not allow sharing the font file with anyone, so it stays on the one licensed machine. If you need Canyon lettering, ask for it as vector outlines (see `tools/canyon/`), or buy another seat.
- **Inter** is open source under the SIL Open Font License 1.1 (https://openfontlicense.org), so it is included.
