# Creative Cave Brand Kit

Everything you need to design for Creative Cave. Start with the guidelines, then grab the files.

## What's in here

| Folder | What it is |
|---|---|
| `guidelines/` | Brand Guidelines PDF (20 pages) and `BRAND.md`, the living written guide |
| `logo/source-ai/` | Illustrator source files: 2026 logo, profile pic, lockup explorations |
| `logo/svg/` | SVG exports of the Illustrator files, for web and quick use |
| `logo/png/` | Logo lockup in navy and white, bear mark |
| `icons/` | Favicon, app icon, touch icon |
| `social/` | LinkedIn banner and site share image |
| `fonts/` | Inter font files, plus where to get the rest (see `fonts/README.md`) |
| `tools/canyon/` | Scripts that turn Canyon lettering into SVG outlines |

## Colors

| Coral Red | `#FD614B` | 253, 97, 75 | 0, 62, 70, 1 |

Three colors, nothing else. Navy on seal, seal on navy, coral as the accent.

## Logo rules, short version

- Never retype the wordmark or even out the weights.
- Nothing behind the logo. No disc, no box.
- The bear's face cutouts stay open so the background shows through.

Full rules are in the PDF.
